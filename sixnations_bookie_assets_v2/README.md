# Six Nations friends-bookie assets (v2)

This is the **math engine** for a small-group bookmaker simulation.

Quick run:

```bash
pip install -r requirements.txt
python demo_sixnations_points_market.py
```

Backend scaffold (optional):

```bash
pip install -r requirements-dev.txt
uvicorn backend_skeleton.main:app --reload
```

See `DEVELOPER_GUIDE.md` for the full build plan.
